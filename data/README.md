# Dataset

The dataset used by RestaurantIQ contains restaurant-level information including location, cuisine, pricing, ratings, votes, and service availability.

## Dataset Status

The raw dataset is **not duplicated in this repository** unless redistribution rights explicitly permit it.

If the dataset is publicly redistributable, it may be placed in this directory using the expected filename documented by the notebooks.

Otherwise, users should obtain the dataset from its original source and place it locally in:

```text
data/
```

## Expected Data Characteristics

The original working dataset contains approximately:

```text
Rows: 9,551
Columns: 21
```

The notebooks perform task-specific preprocessing and filtering.

## Reproducibility

Because the raw dataset is not necessarily redistributed with this repository, users should verify the dataset source and version before reproducing the analysis.
